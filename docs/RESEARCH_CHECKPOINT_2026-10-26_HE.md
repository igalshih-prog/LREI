## 3. הרצה מקומית לשחזור — מחקר על נייר בלבד

דרישות: Git, Python 3.10 ומעלה, חיבור אינטרנט להתקנת תלויות; מפעילים מתוך תיקיית המאגר.

```bash
python -m pip install -e .
python -m pip install pytest
python -m pytest -q -m "not slow"
```

לבחינת ממשק Streamlit, התקינו את חבילת ה־UI והפעילו:

```bash
python -m pip install -e ".[ui]"
python -m streamlit run app.py
```

**זהירות:** אין להסתמך על 14 טורים המוצגים או על קובץ ה־TXT כאסטרטגיית משחק. בדיקת הדפדפן המלאה דורשת Playwright/Chromium והיא נשמרת ב־workflow נפרד; אין להסיק מקיום תלויות UI שהבדיקה המלאה רצה במחשב המקומי.

לבקרת טריות, הריצו (צפוי להחזיר קוד שגיאה כל עוד נתוני המקור אינם טריים):

```bash
python -m lrei.lottery.dataset_freshness --dataset data/lottery.csv
```

**כישלון בקרת הטריות אינו "באג CI" שיש לעקוף**; הוא אות לחוסר כשירות של נתוני מחקר עדכניים. לפרוטוקול קליטת מקור ברשת עצמאית: [הוראות אימות נפרדות](p1-independent-network-source-capture.md). אין להעלות מסמכי זיהוי, מכתבים אישיים או נתוני משתתפים למאגר הציבורי.

## 4. תנאים מוקדמים לסגירת המחקר הכלכלי, לפי סדר

1. **מקור תוצאות עצמאי:** הורדת קובץ מקורי מאתר מפעל הפיס ב־TLS מאומת, שימור bytes מקוריים, SHA-256, תאריך קליטה, זיהוי מקור ורצף הגרלות; השוואת מדגם לפרוטוקולים מאושרים; סקירת זכויות שימוש והגבלת טריות. רק אז לדון בקידום PR #44 או בהחלפתו בקובץ חדש וטרי.
2. **פרסי לוטו:** קבלת 16 דרגות (8 רגיל+8 דאבל) לכל הגרלה חסרה #3955–#3968, כולל כמויות זכייה ותשלום לזוכה ממקור מורשה; אימות מול הגרלות ונספחי תקנון. אין להשלים את 224 התאים מנתונים מנוחשים, נתוני צד ג' או חישובי אומדן. לקבלת מידע רשמי ייתכן תשלום; **לא משלמים ללא החלטת המשתמש**.
3. **היתכנות כלכלית:** אימות היקפי השתתפות, מחירון ותקנון תקפים, מס, התחלקות בפרס; אומדן בחירות משותפות של שחקנים צריך להסתמך על נתונים מצרפיים מורשים או ולידציה עצמאית ולכלול אי־ודאות. מחקרי 2018 האקדמיים מציגים השערות בלבד ל־2026; מידע גולמי תחת NDA אינו זמין באופן חופשי.
4. **ולידציה לפני הכרזה:** הקפאת השערות ופרוטוקול, השוואת Smart 5+ / אקראי / נגד־קהל **באותה עלות**, על תקופת מבחן כרונולוגית שלא שימשה להתאמה. מדד כספי לאחר עלויות, מס וחלוקת פרס עם רווחי אי־ודאות. אם אין עדות ליתרון כספי נטו או אי־הוודאות גדולה — **NO PLAY**.
